Test on the public testnet

The public testnet runs at testnet.trestly.io. It is the whole bridge and the pool on test networks, from the same release as mainnet (mainnet-v0.9.8-rc.25). It is there for developers and integrators to test against, beside the mainnet launch.

Test coins only

Nothing on the testnet has value. Test kUSDT, test USDT and test KAS cannot be exchanged for anything. Never put a recovery phrase that holds real KAS into a testnet build of the wallet.

What it is

Section titled “What it is”

The web app at testnet.trestly.io has the same pages as on mainnet: Bridge, Swap, Pool and Reserves, plus a faucet for test coins. It runs on:

  • Kaspa testnet-10 (TN10), with kaspatest: addresses;
  • Sepolia (chain ID 11155111);
  • BSC testnet (chain ID 97).

The testnet ran from 4 November 2026, was paused on 14 November 2026 and came back the same evening.

Get the wallet and test coins

Section titled “Get the wallet and test coins”
  1. Download the testnet build of kUSDT Wallet: kusdt-wallet-testnet.zip. Its SHA-256 is beside it, at kusdt-wallet-testnet.zip.sha256. Check it before you unzip.
  2. Unzip it. In Chrome, open chrome://extensions, turn on Developer mode, click Load unpacked and pick the unzipped folder.
  3. Create a new wallet in it. Use a fresh recovery phrase, not one that holds real coins.
  4. Open testnet.trestly.io, connect the wallet, and take test kUSDT from the faucet in the web app: 25 kUSDT a claim, once a day per address.
  5. Try the flows: bridge test USDT in, swap, add and remove liquidity, and redeem. The steps are the same as on mainnet (Bridge USDT in, Swap, Redeem kUSDT).

Test your integration here

Section titled “Test your integration here”

Use the testnet to try a wallet, a website or an exchange flow end to end, with real wallets and real networks, before you go to mainnet:

  • Point your code at the testnet API and the testnet addresses above, and keep them in a setting, so that mainnet is a change of configuration, not of code.
  • Try deposits from both chains, redemptions to both chains, swaps, and what your code does while a payout waits.
  • You can still run the whole stack on your own machine instead (Simnet, Build and test).

The testnet is not a promise about mainnet. No independent audit has been done, and the legal review is still open (Audit status, Known limits).
