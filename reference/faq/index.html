FAQ

General

Section titled “General”

What is kUSDT?

Section titled “What is kUSDT?”

A token on Kaspa Layer 1 backed by USDT locked in vaults on Ethereum and BNB Chain. One kUSDT corresponds to one USDT in a vault. See What is kUSDT.

Is kUSDT issued by Tether?

Section titled “Is kUSDT issued by Tether?”

No. kUSDT is a bridged token. The vaults hold USDT on Ethereum and BSC-USD on BNB Chain; kUSDT is not issued by the issuers of those tokens. kUSDT’s own rules are the covenants and contracts described here.

Is it live?

Section titled “Is it live?”

On testnet only: TN10, Sepolia and BSC testnet, since 4 November 2026. The public testnet is at kusdt.pearlchain.live, with test coins only, and the testnet wallet can be downloaded. Nothing is on mainnet. See Test on the public testnet and Status.

Who runs the testnet?

Section titled “Who runs the testnet?”

One public test host runs every service, each in its own isolated container: a TN10 node, the five signers, the coordinator, the monitor and the web app. That is a testnet convenience. On mainnet each signer is a different operator on its own machine. See Operations.

Has it been audited?

Section titled “Has it been audited?”

No. See Audit status.

Does kUSDT use Igra or Kasplex?

Section titled “Does kUSDT use Igra or Kasplex?”

No. kUSDT runs on Kaspa L1 only. See Kaspa L1, not a layer 2.

Using kUSDT

Section titled “Using kUSDT”

How do I get kUSDT?

Section titled “How do I get kUSDT?”

Deposit USDT into the vault on Ethereum or BNB Chain (Bridge USDT in), or buy it with KAS in KasPool (Swap).

What does bridging cost?

Section titled “What does bridging cost?”

0.20 % each way. The minimum is 0.50 USDT per deposit, and 5 USDT (Ethereum) or 0.50 USDT (BNB Chain) per release on mainnet; on the testnet both chains’ minimum release fee is 0.50 USDT. You also pay gas on the EVM chain and a network fee in KAS on Kaspa. See Fees.

Why does my kUSDT UTXO hold KAS?

Section titled “Why does my kUSDT UTXO hold KAS?”

Kaspa requires each UTXO to carry KAS for the storage it uses, and covenant UTXOs count double. Each kUSDT state carries about 1.5 KAS. It remains yours and moves with the token. The exception is a redemption’s burn output: it carries 0.3 KAS, which is gone for good, since nothing can spend a burn. See Storage mass.

Can I redeem on a different chain from the one I deposited on?

Section titled “Can I redeem on a different chain from the one I deposited on?”

Yes. kUSDT is one token. A redemption names the payout chain, and that chain’s vault pays it if it holds enough backing. See Known limits.

What if I send a burn to the wrong address?

Section titled “What if I send a burn to the wrong address?”

The payout goes to that address. Nobody can redirect it, including you. Check the address before you sign.

Is there a minimum redemption?

Section titled “Is there a minimum redemption?”

A burn must be larger than the release fee: more than 5 USDT on Ethereum, more than 0.50 USDT on BNB Chain. Smaller burns are never paid.

Can the bridge freeze my kUSDT?

Section titled “Can the bridge freeze my kUSDT?”

No. The guardian can pause minting, the vaults and the pool, but kUSDT transfers on Kaspa have no pause. A paused pool stops swaps and new liquidity; liquidity providers can still withdraw.

What if USDT blacklists my address?

Section titled “What if USDT blacklists my address?”

The bridge pays nothing to an address the token blocks: the USDT would be frozen there for good. Only Ethereum USDT keeps a blacklist; BSC-USD keeps none. The wallet and the web app check the address before every burn and refuse a blocked one. If such a burn lands anyway, it is held and paid if Tether unblocks the address. Nobody can send it elsewhere. See Blocked recipients.

Which wallets support kUSDT?

Section titled “Which wallets support kUSDT?”

Any wallet with KCC-20 support can read kUSDT states, because kUSDT uses the standard template. The kUSDT wallet extension has a testnet build to download (Install) and is not in any store yet. Always check the covenant ID.

Security

Section titled “Security”

Who controls the bridge?

Section titled “Who controls the bridge?”

Five independent signers; any 3 approve a mint or a payout. Both sides limit how much can move per day. See the trust model.

What happens if 3 signers are compromised?

Section titled “What happens if 3 signers are compromised?”

They could mint unbacked kUSDT up to the Kaspa allowance (500 000 USDT at once) and pay out from each vault up to its release allowance (250 000 USDT at once), each refilling over 24 hours. They cannot undo the guardian’s pause: unpausing the minter takes 4 signers, and unpausing a vault takes the owner. See the threat model.

Can the coordinator steal funds?

Section titled “Can the coordinator steal funds?”

No. It holds no key that moves funds. It can only stall the bridge.

Can the vault owner take the USDT?

Section titled “Can the vault owner take the USDT?”

Not directly: no function lets the owner withdraw backing. It could, after the 48-hour timelock, replace the vault’s signers and raise its limits within the hard bounds. That is why the owner is a timelocked Safe. See Governance.

Is the pool safe from sandwich attacks?

Section titled “Is the pool safe from sandwich attacks?”

Yes. A swap spends the exact pool state it was built on and names the exact output, so a competing swap makes it invalid rather than worse. See KasPool.
